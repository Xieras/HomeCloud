# HomeCloud Connect — программа для Windows

Небольшая программа, в которой вы один раз вводите IP-адрес (или домен) своего хранилища,
сохраняете его — и дальше открываете хранилище одной кнопкой. Умеет:

- хранить несколько адресов (дом, дача, домен снаружи, Tailscale…) и отмечать один как **основной**;
- показывать, какие из них сейчас **в сети** (зелёным — отвечает, красным — нет);
- открывать выбранный адрес в браузере (двойной клик или Enter);
- при желании сразу открывать основное хранилище при запуске (Shift при запуске — показать окно).

Адреса лежат в `%APPDATA%\HomeCloud\servers.json` и не отправляются никуда, кроме проверки «жив ли сервер»
(обычный запрос страницы `/login` вашего же хранилища).

> На сайте есть такой же раздел — **«Хранилища»** в левом меню. Это отдельный список: он хранится на сервере в вашем
> аккаунте, а список в программе — на вашем компьютере. Между собой они не синхронизируются.

## Как получить `.exe` и установщик

Программа написана на C# и собирается **компилятором, который уже встроен в Windows 10/11**
(`csc.exe` из .NET Framework 4.x). Поэтому не нужны ни Visual Studio, ни Python, ни интернет.

### Способ 1. На своём компьютере с Windows (проще всего)

1. Распакуйте репозиторий и откройте папку `windows`.
   *Зачем:* скрипт сборки берёт исходники и иконку по относительным путям, поэтому запускать его нужно из этой папки.
2. Дважды щёлкните **`build.bat`**.
   *Зачем:* скрипт сам находит `csc.exe` в `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\` и вызывает его два раза.
3. Дождитесь строки `DONE`. Первый шаг собирает саму программу, второй — установщик и **вкладывает программу внутрь него**.
   *Зачем так:* установщик получается одним файлом — его не нужно пересылать вместе с чем-то ещё.
4. Готовые файлы появятся в `windows\dist\`:

| Файл | Что это |
|---|---|
| `HomeCloudConnect-Setup.exe` | установщик — его отдавайте друзьям |
| `HomeCloudConnect.exe` | сама программа без установки (можно запускать с флешки) |

Если сборка упала, скрипт покажет имя файла и номер строки с ошибкой. Если написано, что `csc.exe` не найден, включите
«Компоненты Windows → .NET Framework 4.8 Advanced Services».

### Способ 2. Через GitHub, без запуска чего-либо у себя

Если репозиторий лежит на GitHub: вкладка **Actions → Windows build → Run workflow**. Через минуту-две в разделе
**Artifacts** появится архив `HomeCloudConnect-Windows` с обоими файлами. Файл сценария — `.github/workflows/windows-build.yml`.

## Установка и удаление

Запустите `HomeCloudConnect-Setup.exe`, при желании измените папку, нажмите «Установить».

- Права администратора **не нужны**: программа ставится в `%LocalAppData%\Programs\HomeCloud Connect` только для вашего
  пользователя. Поэтому не появляется запрос UAC, и на общем компьютере никому ничего не мешает.
- Создаётся ярлык в меню «Пуск» (и по желанию на рабочем столе) и запись в «Параметры → Приложения».
- Удалить: «Параметры → Приложения → HomeCloud Connect → Удалить». Установщик спросит, стирать ли сохранённые адреса.
- Тихая установка (для скриптов): `HomeCloudConnect-Setup.exe /silent`.

### Предупреждение SmartScreen / антивируса

Файл не подписан цифровой подписью (она платная), поэтому при первом запуске Windows может написать
«Windows защитила ваш компьютер». Нажмите **«Подробнее → Выполнить в любом случае»**. Это нормально для любых программ без
подписи от небольших авторов. Если собирали сами — вы знаете, что внутри: весь код в `src\`.

## Положить установщик на сайт

Чтобы друзья скачивали его прямо с вашего хранилища:

1. Скопируйте `HomeCloudConnect-Setup.exe` на сервер в `/opt/homecloud/static/downloads/`
   (папку создайте: `sudo mkdir -p /opt/homecloud/static/downloads`).
   *Зачем именно сюда:* nginx отдаёт всё из `/opt/homecloud/static/` напрямую, а сайт ищет файл по этому пути.
2. Права: `sudo chown -R homecloud:homecloud /opt/homecloud/static/downloads`.
3. Перезапуск не нужен: на странице «Хранилища» сам появится блок «Программа для Windows» с кнопкой «Скачать».

Файл доступен по прямой ссылке без входа — в нём нет ничего секретного, это просто клиент.

## Что где лежит

```
windows/
  build.bat                 — сборка в один клик
  src/HomeCloudConnect.cs   — программа
  src/Installer.cs          — установщик / деинсталлятор
  src/app.manifest          — без запроса прав администратора, чёткий текст на экранах с масштабом
  src/app.ico               — иконка (та же, что у сайта)
  dist/                     — сюда попадает результат сборки
```

Код специально написан на C# 5: более новые возможности языка встроенный в Windows компилятор не понимает.

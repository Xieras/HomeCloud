# HomeCloud

Личное файловое хранилище на домашнем сервере (Debian 12): Flask + SQLite + gunicorn + nginx.

## Установка

```bash
# скопируйте папку homecloud на сервер, затем:
cd homecloud
sudo bash deploy/install.sh
```

Скрипт ставит пакеты, создаёт пользователя `homecloud`, окружение Python, сервис systemd,
конфиг nginx, fail2ban, logrotate и файрвол, а также создаёт администратора из `.env.example`.
После создания пароль из `.env` удаляется — в базе остаётся только его хеш.

Дальше: проброс портов 80/443 на роутере, домен (или DDNS), затем `certbot --nginx -d ваш.домен`.
Если вход идёт по http://IP без HTTPS — временно `COOKIE_SECURE=0` в `/opt/homecloud/.env`.

## Права

| Права | Что можно |
|---|---|
| Только чтение | смотреть и скачивать файлы |
| Чтение и изменение | плюс загрузка, папки, переименование, удаление |
| Администратор | всё хранилище + панель «Доступы» и «Журнал» |

Администратор назначается только на сервере (`create-admin`), из веб-панели им сделать нельзя.
Для любого пользователя можно ограничить одну папку — выше неё он ничего не увидит.

## Админ-панель (`/admin`)

Выдача доступа (почта, пароль, права, папка), смена пароля, отключение и удаление,
журнал входов (включая неудачные) и всех действий с файлами с поиском и фильтром.

## Сервисные команды

```bash
cd /opt/homecloud
sudo -u homecloud ./venv/bin/flask --app app set-password почта@example.com   # сброс пароля
sudo -u homecloud ./venv/bin/flask --app app create-admin почта@example.com   # назначить админом
sudo journalctl -u homecloud -f                                                # логи сервиса
sudo systemctl restart homecloud
```

Данные: файлы — `/srv/storage`, база — `/var/lib/homecloud/app.db` (делайте её резервные копии).

## Безопасность

- Пароли хранятся хешами (scrypt), вход ограничен по частоте (5 неудач за 15 минут с одного IP),
  плюс nginx `limit_req` и fail2ban (бан IP на 2 часа).
- Защита от CSRF, выхода за пределы папки, строгий CSP, cookie `HttpOnly`/`Secure`/`SameSite`.
- Для максимальной защиты вместо открытия портов в интернет используйте WireGuard или Tailscale.
